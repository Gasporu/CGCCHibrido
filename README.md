# Comandos da aplicação

TAB: Seleciona o próximo objeto da cena. O objeto selecionado ficará com um tom levemente esverdeado.

Teclas + e - (do teclado principal e do numérico): Aumenta e diminui o tamanho do objeto selecionado.

J e L: Gira o objeto selecionado para a esquerda/direita (em torno do eixo Y).

I e K: Gira o objeto selecionado para cima/baixo (em torno do eixo X).

U e O: Inclina o objeto selecionado para os lados (em torno do eixo Z).
